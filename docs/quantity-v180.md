# 小時、單字與教材每週目標

## 入口

- 教材庫：「擴充教材：小時／個單字」。先建立一個完整單元，例如影片1.5小時、單字120字，不必建立每日切片。
- 智慧排程：「每週目標／份量排程」。原先沒有實際套用的每週參考欄位改為通往此入口。
- 月曆手動新增：「安排小時／單字份量」。可先使用單日範圍，再調整日期。

## 資料

既有 masters、頁碼、unitBased 不轉換。擴充單元存於各學生的 quantityCatalog；每個單元及教材有固定 ID。quantityRules 保存最後確認過的分類／任務目標。既有全機備份所包含的 Family JSON 會一併保存這些欄位。

擴充任務保留 userId、unitId、materialId、cat、mis、科目與教材名稱，並使用 measure、quantityStart、quantityEnd。時間內部為秒，單字內部為零起始位置；區間採左含右不含，畫面轉回時間碼或第1～15字。完成紀錄的 pages 為0，不冒充紙本頁數。紙本舊遷移及名稱重配不處理有 measure 的任務。

已排程的擴充單元不可直接修改或移除，以免舊任務範圍失真。未排程者可編輯、刪除。新單元可以繼續加到同一本擴充教材。

## 配額規則

每列依「科目／教材」設定每日或每週數量與該份量的預估學習時數。影片內容小時與實際學習成本分開設定；單字數不代表熟悉度。每週為週一到週日，部分週仍要求完整目標；每日目標只適用於可用時數大於0的日期。

紙本來源只讀取選定任務內具有教材、單元 ID 及有效頁碼的項目；缺資料者不猜測為 P.1，不改動原教材。份數以一單元為一份；本版新增的週配額以整單元排入單日，若無一天可容納其預估時數，會列出缺口，不能強制提交。已排了一部分的紙本單元不自動猜成完整一單元，需先從原編輯功能確認剩餘安排。

既有相同分類／任務排程計入數量與每日負擔，重疊範圍去重。既有沒有 estimatedHours 的任務暫以每筆1小時扣除，畫面明示此假設。不同教材各自成列；同一單元有重疊目標時拒絕。依列順序分配可用時數，使用者須核對預覽。時間或教材不足時不提交任何部分草稿，請調整目標、日期或時數。已全部安排且沒有新增內容時不建立空計畫。

## 調整、顯示與安全

月曆點選小時／單字任務可縮短本筆迄點，預覽後選擇後續開始日期與完成天數或暫不安排。已由其他排程涵蓋的部分不重複新增；本筆完成狀態保留，新增剩餘任務為未完成。可刪除單筆排程，教材仍保留。

月曆與兩種列印版型使用共同格式與分類／任務篩選。學習統計另有擴充教材概覽，明示目前學生、所有分類／任務範圍，與原紙本統計分開。

所有新增與配額操作先建立草稿，最終確認才寫入 Family。寫入前核對學生、記憶體快照與原存檔；衝突、失敗不把草稿套入目前記憶體。正式資料不自動轉換，不使用 Safari 正式儲存做測試。

## 效能

智慧排程點按先顯示載入狀態，下一個繪製週期才計算。分類／任務確定後只建立一次科目清單；非第一科的細目按展開才繪製，所有選取仍保存在資料中。切換學生或關閉視窗會取消尚未執行的載入。

測試使用合成資料；瀏覽器紀錄的耗時不能當成個人正式資料的效能保證。

原智慧排程遇到新份量／配額任務時會扣除其 estimatedHours；單元模式若超過這些任務剩下的當日時數，會拒絕提交並提示缺口。僅含舊任務時沿用原有時數估計行為，不更改既有計量。
