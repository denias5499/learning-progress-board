# 現行測試與歷史斷言的處理

v2.3.2.178 已逐項處理原本 151 項跳過測試。這不表示 151 個舊斷言全部通過；過時版本與已淘汰實作不再作為現行功能規格。

| 處理 | 數量 | 驗證方式 |
| --- | ---: | --- |
| 保留現行排程檢查並重新啟用 | 2 | 保留原本非版本斷言，另有實際排程測試 |
| 過時版本號整併 | 35 | 發布 manifest、頁面 title 與教材庫版本徽章一致性測試 |
| 舊畫面、事件、樣式、流程改寫／整併 | 112 | 現行介面、資料內容、事件操作及真實瀏覽器驗證 |
| 已確認不適用的舊規則退役 | 2 | 不跨教材刪除單元、未排程單元不借完成度 |

完整對照、原始斷言、SHA-256、處理原因與替代測試，見 [retired-tests-v178.json](retired-tests-v178.json)。舊原文以 JSON 保存，不能把它們搬到另一個可執行目錄後繼續隱藏失敗。

新增 `retirement-coverage.test.js` 檢查每一筆都有可執行的替代驗證，現行 `.test.js` 也不得再留下未處理的 `test.skip` 或 `test.todo`。原先已可執行的部分沒有直接刪除：4項排程原始碼位置斷言隨新變數／分支更新；另有10項舊自動修正算法測試，依本人確認的新天數規則改寫為10項實際排程／設定保護案例。這10項的原文及理由另存 `confirmed-rule-updates-v178.json`，不混入151項統計。

`npm test` 執行 Node／DOM 回歸。真實瀏覽器檢查由 CI 安裝 Chromium 後執行：

```sh
node test/e2e/current-contracts.e2e.cjs
```

瀏覽器使用獨立資料環境、動態本機連接埠與合成圖片，涵蓋模式選擇、實際版面對齊、iframe 導覽及捲動、圖片裁切與 IndexedDB 存回讀出。測試結束即關閉，不留下會重設資料的 QA 頁，也不讀取個人 Safari／Chrome 資料。

「錯題數據分析」及「錯題再練」目前仍是建置中提示，本輪沒有把它們當成已實作功能。舊版 `test/legacy/` 的其他檔案也不在這 151 項處理範圍；不以這次整併宣稱所有歷史測試或功能皆已驗證。
